📊 Google Sheets Two-Way Sync Setup
Connects your existing RuPay Benefits - 2026 spreadsheet directly with this app. Columns A to M (Account, Card, Benefit, Brand, Booking ID, Coupon Code, etc.) will read & write seamlessly, while preserving your summary tables in Column O+.
1
Open Google Apps Script: In your Google Sheet, click Extensions ➔ Apps Script in the top menu bar.
2
Paste Script Code: Replace any code in Code.gs with the script and click Save (💾).
3
Deploy as Web App: Click Deploy ➔ New deployment (top-right).
  • Select type: Web app
  • Execute as: Me (your Google email)
  • Who has access: Anyone
4
Paste Web App URL: Copy the generated Web App URL (ending in /exec) and paste it into the URL field in Settings. Click Test Connection.
